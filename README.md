# Partytury

Program do porządkowania PDF-ów z partiami (usuwanie duplikatów, kolejność jak w partyturze,
wyodrębnianie partii, np. basu, z wielu utworów naraz) z automatycznym rozpoznawaniem
nazw instrumentów (Tesseract OCR).

**Instalator:** zakładka *Releases* po prawej → najnowsza wersja → `Partytury-setup.exe`.

Instalator buduje się sam (zakładka *Actions*) po każdej zmianie plików w tym repozytorium.
